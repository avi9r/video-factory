Manual Script Editor

Paste JSON from Cursor/ChatGPT or fill the structured form below.

Required script format
  1. Outline — title, title_variations, description, tags, hero_visual_prompt (for one-image videos)
  2. Hook — text, visual_prompt, broll_prompt, emotion, narration_tone, sfx_cues
  3. Act 1 — act_title + scenes (scene_id, narration, visual_prompt, emotion, narration_tone, sfx_cues)
  4. Act 2 — same structure
  5. Act 3 — same structure
  6. Outro — text, visual_prompt, emotion, narration_tone, sfx_cues

scene_id naming: hook, act1_scene1, …, outro

sfx_cues example: [{"sound_id":"rain_light","start_offset_sec":0,"duration_sec":12,"volume":0.08}]

Cursor workflow — generate JSON in chat, save to content_json/, then load here. See content_json/GENERATE.md.

Voice pacing — markers are auto-added on save ([pause] [slow] [breath] [emphasis]). Preview with Add Pacing Markers below.
